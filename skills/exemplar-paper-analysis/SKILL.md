# Exemplar Paper Analysis

Extract transferable writing architecture from strong papers while keeping the user's research and wording independent.

## Workflow

1. Confirm the target venue, article type, discipline, and the role of each exemplar.
2. Map each paper by section, subsection, paragraph purpose, main claim, evidence type, and transition.
3. Identify recurring rhetorical moves: motivation, gap, contribution, method justification, result description, mechanism interpretation, limitation, and implication.
4. Map every figure or table to the question it answers and the paragraph sequence around it.
5. Separate venue conventions from paper-specific scientific claims and author-specific phrases.
6. Produce a reusable outline using functional labels and placeholders rather than copied sentences.

## Output

Return a comparison matrix, section blueprint, paragraph-function map, figure-driven narrative map, reusable patterns, and patterns that should not be copied.
