# Scientific Data Analysis

Keep raw data immutable and make every transformation reproducible.

## Workflow

1. Inventory files, variables, units, groups, replicates, missing values, and provenance.
2. Preserve raw files; write cleaned data and an explicit transformation log separately.
3. Validate ranges, duplicates, identifiers, outliers, and unit consistency without silently deleting observations.
4. Choose analyses from the study design and research question, not from the desired result.
5. Check model or test assumptions, report effect sizes and uncertainty, and distinguish exploratory from confirmatory analysis.
6. Generate reproducible code, tables, and a result summary tied to exact outputs.

## Output

Deliver an audit log, analysis plan, reproducible script, result tables, diagnostics, figure-ready data, limitations, and manuscript-safe statements. Never invent values or report unsupported significance.
