# Imitation Writing Practice

Use exemplars as structural teachers, never as text to paraphrase line by line.

## Workflow

1. Select one target section and identify its required scientific evidence.
2. Extract the exemplar's paragraph functions and logical sequence.
3. Build a fresh outline using the user's verified data, methods, figures, and citations.
4. Draft original sentences from that outline; preserve uncertainty and do not add unsupported claims.
5. Compare the draft with the exemplar at the structural level: coverage, order, density, transitions, and evidence placement.
6. Revise for independence, then identify missing evidence and weak reasoning.

## Output

Return the structural model, the new draft, a comparison table, originality safeguards, and a focused revision exercise. Never copy distinctive wording or fabricate data and citations.
