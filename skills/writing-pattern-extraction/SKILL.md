# Writing Pattern Extraction

Learn how sentences work, not their exact wording.

## Workflow

1. Group passages by communicative function rather than surface vocabulary.
2. Decompose each passage into slots such as context, limitation, evidence, contrast, mechanism, uncertainty, and implication.
3. Keep only patterns that recur across multiple sources or clearly reflect the target venue.
4. Rewrite patterns as abstract templates with placeholders, for example: `[prior approach] achieves [benefit] but remains limited by [constraint]`.
5. Record when each pattern is appropriate and what evidence it requires.
6. Flag distinctive phrases, long sequences, or author-specific wording that must not be reused.

## Output

Produce a categorized pattern library with purpose, template, evidence requirements, usage notes, and an original example created from neutral placeholder content.
