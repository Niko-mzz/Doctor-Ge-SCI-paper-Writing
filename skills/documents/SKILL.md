# Documents

Use a render-and-inspect workflow for every final DOCX.

## Workflow

1. Inspect the source document, template, styles, sections, headers, footers, tables, figures, captions, and page setup.
2. Preserve the controlling template when one is provided; avoid replacing its styles with generic defaults.
3. Use an appropriate DOCX library or OOXML editing for deterministic changes.
4. Apply real Word styles, numbering, fields, captions, and table geometry rather than visual text imitations.
5. Save non-destructively unless replacement is explicitly requested.
6. Render the DOCX to PDF or page images and inspect every page for overflow, clipping, blank pages, broken tables, misplaced figures, font substitution, and inconsistent spacing.
7. Iterate until visual and structural checks pass.

## Quality Checks

Verify headings, pagination, cross-references, captions, chemical or mathematical notation, bibliography layout, image resolution, accessibility, and file opening. Report the final absolute path and do not deliver QA intermediates unless requested.
