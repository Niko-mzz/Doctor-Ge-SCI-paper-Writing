# Reference Management

Build a clean, traceable reference library without changing scientific meaning.

## Workflow

1. Import every available bibliography file and manuscript reference list.
2. Normalize names, titles, venues, dates, identifiers, capitalization, and page ranges while preserving authoritative spelling.
3. Deduplicate by DOI or PMID first, then normalized title and author-year comparison.
4. Assign stable citation keys and preserve a mapping from original to normalized records.
5. Reconcile cited, uncited, and missing references against the manuscript.
6. Apply the target journal's current citation style only after verifying its instructions.

## Deliverables

Produce a cleaned bibliography, duplicate report, missing-reference report, citation-key mapping, and a summary of records requiring human verification. Do not fabricate DOI values or complete partial references from memory.
